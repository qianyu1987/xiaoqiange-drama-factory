# 小钱哥短剧工厂

Windows 10/11 客户版。首次购买 498 元，包含 399 元永久单机授权和 99 元首个 31 天生成订阅；后续续费 99 元 / 31 天。每位客户使用独立生成套餐，不与其他客户共用凭据或额度。

## 使用

1. 安装 Node.js 22 LTS。
2. 解压本 ZIP，不要移动或删除 `backend`、`frontend`、`tools` 文件夹。
3. 双击 `start.bat`，浏览器打开本地工作台。
4. 输入购买后收到的一次性产品授权码。
5. 停止服务时双击 `stop.bat`。

## 版本更新

程序启动后会自动检查官方更新。发现新版本时，工作台会显示更新提示；点击更新后会先校验更新包并备份本地数据库，再替换程序文件并自动重启。更新不会覆盖 `%APPDATA%\小钱哥短剧工厂` 中的数据库、授权信息、备份，也不会覆盖 `%USERPROFILE%\Videos\小钱哥短剧工厂` 中的作品。

本程序不提供 EXE 安装器。数据库、授权信息和备份保存在 `%APPDATA%\小钱哥短剧工厂`，视频和导出文件保存在 `%USERPROFILE%\Videos\小钱哥短剧工厂`。
