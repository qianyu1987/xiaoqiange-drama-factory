# 第三方服务与版权清单

- LocalMiniDrama 上游项目：MIT License，保留仓库 `LICENSE` 与原作者版权声明。
- Electron、Vue、Express、SQLite 及 npm 依赖：按各自许可证使用，发行前由构建流水线生成依赖许可证清单。
- FFmpeg：Windows 商品包仅允许经构建检查确认的 LGPL 构建，并随安装包提供 `LICENSE.txt`、`SOURCE.txt` 及运行所需动态库。仓库中的 macOS arm64 GPL FFmpeg 不进入 Windows 商品包。
- HHTC、Agnes 及其他模型服务：按各自服务条款和内容政策处理生成请求。上游渠道可因额度、健康度和成本自动切换。
- 内置音乐库只能收录已取得明确商业授权的音频，并为每个文件保留授权来源、授权范围和校验值。没有授权记录的音乐不得进入商品包。
