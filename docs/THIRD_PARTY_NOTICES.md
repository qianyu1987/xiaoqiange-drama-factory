# 第三方服务与版权清单

- LocalMiniDrama 上游项目：MIT License，保留仓库 `LICENSE` 与原作者版权声明。
- Vue、Express、SQLite 及 npm 依赖：按各自许可证使用，发行前由构建流水线检查依赖和发布内容。
- FFmpeg：Windows 商品包仅允许经构建检查确认的 LGPL 构建，并随安装包提供 `LICENSE.txt`、`SOURCE.txt` 及运行所需动态库。仓库中的 macOS arm64 GPL FFmpeg 不进入 Windows 商品包。
- HHTC 负责账号、授权和模型网关；客户商业版的文本、图片、视频请求只使用该客户专属 Agnes Token Plan Key 对应的能力。缺少能力或额度耗尽时停止生成，不切换到公共渠道、其他客户凭据或其他供应商。
- 视频中的人物对白、环境音和背景音乐由视频模型原生生成；客户仍需在发布前确认生成声音及内容满足平台规则和商业使用要求。
