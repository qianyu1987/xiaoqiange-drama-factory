# 小钱哥短剧工厂隐私说明

生效版本：2.0.0

## 本地保存

项目数据库、生成产物、发布包和备份默认保存在客户电脑。设备刷新令牌由 Windows DPAPI/Electron `safeStorage` 加密。诊断包不包含项目数据库、媒体文件、完整令牌或 API Key，并在生成时执行脱敏。

## 云端处理

HHTC 保存账号、订阅、设备指纹摘要、余额账本、任务清单、进度、成本和错误码。为完成客户主动发起的生成任务，故事文本、提示词、参考图片和生成参数会发送到 HHTC 以及实际执行任务的第三方模型服务。发布包和本地数据库不会默认上传。

## 保留与删除

账单和交易记录按适用法律及财务要求保留。客户可解绑设备并申请删除非强制保留的账号数据。自动备份最多保留最近 10 份，客户可在本机删除。

## 安全

公网接口必须使用 TLS。上游主密钥只保存在 HHTC 服务端。正式更新包必须通过 SHA-256 和 Windows Authenticode 校验。
