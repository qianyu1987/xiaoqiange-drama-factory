# 小钱哥短剧工厂隐私说明

生效版本：2.0.10

## 本地保存

项目数据库、生成产物、发布包和备份默认保存在客户电脑。设备刷新令牌通过 Windows DPAPI 加密。诊断包不包含项目数据库、媒体文件、完整令牌或上游凭据，并在生成时执行脱敏。

## 云端处理

HHTC 保存账号、永久授权、订阅、设备指纹摘要、激活记录、用量事件、任务状态和错误码。为完成客户主动发起的生成任务，故事文本、提示词、参考图片和生成参数会发送到 HHTC 及实际执行任务的模型服务。临时参考图按过期时间清理；发布包和本地数据库不会默认上传。

## 保留与删除

账单和交易记录按适用法律及财务要求保留。客户可解绑设备并申请删除非强制保留的账号数据。自动备份最多保留最近 10 份，客户可在本机删除。

## 安全

公网接口使用 TLS。客户专属上游凭据只在 HHTC 服务端加密保存，不写入客户软件。正式更新包通过受信任的 HTTPS 地址和 SHA-256 校验。
